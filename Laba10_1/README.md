# Приложение "Лаборатория исследователя"

## Описание
Приложение для управления данными исследователей с регистрацией, авторизацией и восстановлением пароля через email.

## Функционал
1. **Регистрация нового пользователя** - данные сохраняются в PostgreSQL
2. **Авторизация** - вход по email и паролю
3. **Восстановление пароля** - код подтверждения отправляется на email через SMTP
4. **Просмотр профиля** - отображение данных исследователя

## Настройка перед запуском

### 1. Настройка подключения к PostgreSQL (файл `bd.cs`)

Откройте файл `bd.cs` и измените строку подключения:

```csharp
var connectionString = "Host=localhost;Database=ResearcherLabDB;Username=postgres;Password=your_password";
```

Замените параметры на ваши:
- `Host` - адрес сервера PostgreSQL (обычно `localhost`)
- `Database` - имя базы данных (будет создано автоматически)
- `Username` - имя пользователя PostgreSQL
- `Password` - пароль пользователя PostgreSQL

### 2. Настройка SMTP для отправки email (файл `email.cs`)

Откройте файл `email.cs` и настройте параметры SMTP:

```csharp
private const string SmtpHost = "smtp.mail.ru";
private const int SmtpPort = 587;
private const string SenderEmail = "your_email@mail.ru";
private const string SenderAppPassword = "your_app_password";
```

#### Для Mail.ru:
1. Зайдите в настройки почты
2. Включите "Пароли приложений"
3. Создайте новый пароль для приложения
4. Используйте его вместо обычного пароля

#### Для Gmail:
1. Включите двухфакторную аутентификацию
2. Создайте "Пароль приложения" в настройках аккаунта Google
3. Используйте: `SmtpHost = "smtp.gmail.com"`, `SmtpPort = 587`

#### Для Yandex:
1. Создайте "Пароль приложений" в настройках Яндекс ID
2. Используйте: `SmtpHost = "smtp.yandex.ru"`, `SmtpPort = 465`

## Установка зависимостей

Проект использует следующие NuGet пакеты:
- `Npgsql.EntityFrameworkCore.PostgreSQL` - работа с PostgreSQL
- `Konscious.Security.Cryptography.Argon2` - хэширование паролей
- `Microsoft.EntityFrameworkCore` - ORM

Для установки выполните в консоли Package Manager:
```
Update-Package
```

## Структура базы данных

### Таблица `researchers`
- `Id` - первичный ключ
- `first_name` - имя
- `last_name` - фамилия
- `date_of_birth` - дата рождения
- `email` - email (уникальный)
- `password` - хэш пароля (Argon2id)
- `phone_number` - телефон
- `research_field` - область исследования
- `first_publication_date` - дата первой публикации

### Таблица `password_reset_codes`
- `Id` - первичный ключ
- `email` - email пользователя
- `code` - код подтверждения (6 цифр)
- `created_at` - время создания
- `is_used` - флаг использования

## Безопасность
- Пароли хэшируются алгоритмом Argon2id с солью
- Код восстановления действителен 15 минут
- После использования код помечается как использованный
- SSL соединение при отправке email

## Возможные ошибки и решения

### "Ошибка подключения к базе данных"
1. Проверьте, запущен ли PostgreSQL сервер
2. Убедитесь в правильности логина/пароля в `bd.cs`
3. Проверьте права пользователя на создание баз данных

### "Ошибка SMTP"
1. Проверьте правильность SMTP настроек в `email.cs`
2. Убедитесь, что используете "пароль приложения", а не обычный пароль
3. Проверьте, не блокирует ли брандмауэр соединение

### "Пользователь не найден"
Пользователь с таким email не зарегистрирован. Нажмите "Регистрация" для создания нового аккаунта.
